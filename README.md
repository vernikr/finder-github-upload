# Finder → GitHub Upload

Quick Action для macOS 15: выделите файлы и папки в Finder, отправьте их одной фиксацией в новую папку `vernikr-personal/uploads` и получите ссылку в буфере обмена. Прогресс показывается в Terminal: число **полностью загруженных файлов** и процент от общего количества; это не индикатор байтов. Публикация коммита занимает дополнительное время после 100%.

> **Важно:** если репозиторий `uploads` публичный, каждый, у кого есть интернет, может увидеть загруженные данные. Не отправляйте секреты, персональные данные или материалы, которые нельзя публиковать. Ссылка не является секретной. Сам инструмент рассчитан на конкретный репозиторий, для другого необходимо изменить OWNER и REPO в `upload.py` до установки.

## Установка

1. Скачайте исходный код репозитория через **Code → Download ZIP** или архив исходников релиза; распакуйте. Запускайте только код, который вы проверили и которому доверяете.
2. Откройте `install.command` двойным щелчком. Если macOS не даёт его запустить: правый клик → **Открыть** → **Открыть**, либо в Terminal выполните `cd путь/к/распакованной/папке` и `bash install.command`.
3. Установщик использует существующий `uv` или скачивает и запускает официальный установщик `https://astral.sh/uv/install.sh`; далее `uv` загружает Python 3.12. Не нужны Homebrew, MacPorts, pnpm, Git, Xcode или готовый Python. В зависимости от конфигурации сети могут потребоваться доступ к сайтам Astral и GitHub. Установщик работает от вашего пользователя, `sudo` не нужен. Загружаемый установщик uv исполняется локально; проверьте его заранее, если этого требуют ваши правила безопасности.
4. В GitHub создайте **fine-grained personal access token**: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Resource owner — `vernikr-personal`; Repository access — **Only select repositories** → `uploads`; Repository permissions → **Contents: Read and write** (Metadata — read-only автоматически). Укажите срок действия. Если репозиторий организации, может понадобиться одобрение владельца и/или SSO. Токен должен иметь именно доступ к целевому репозиторию и возможность записи в его default branch. Правила защиты ветки могут запрещать прямые коммиты.
5. Вставьте токен в окно Terminal установщика: символы не будут отображаться. Он проверяет доступ на чтение и наличие права записи и сохраняет токен в macOS Keychain. При сохранении системная утилита `security` на короткое время получает токен как аргумент процесса; другие процессы того же пользователя могут в этот момент увидеть аргументы. Не вставляйте токен в публичный чат, репозиторий или скриншот. Чтобы заменить токен, повторно запустите установщик. Права записи проверяются по ответу GitHub, но защита ветки может отказать позже.
6. Если действие не видно, откройте **System Settings → General → Login Items & Extensions → Extensions → Finder** (названия могут немного отличаться) и включите **GitHub Upload**. При необходимости перезапустите Finder или выйдите из системы и войдите снова.

## Разрешения macOS

* При первом запуске macOS может запросить разрешение для Automator/Finder управлять **Terminal**: разрешите. Если отказали, включите в **System Settings → Privacy & Security → Automation** для приложения, показанного в запросе.
* Доступ к Desktop, Documents, Downloads и съёмным дискам может запрашиваться отдельно. Разрешите доступ для Terminal или другого приложения, указанного в диалоге, в **Privacy & Security → Files and Folders**. Если этого недостаточно, можно точечно выдать Terminal **Full Disk Access**, понимая, что это расширенный доступ ко всем файлам; обычно он не нужен.
* Keychain может попросить разрешить чтение сохранённого токена. При отказе загрузка не выполнится.
* Системные сообщения отличаются в зависимости от версии и языка macOS. Finder Quick Action работает от имени текущего пользователя.

## Использование

Выделите в одной папке Finder файлы и/или папки → правый клик → **Quick Actions / Быстрые действия → GitHub Upload**. Откроется Terminal с прогрессом. После публикации появится диалог, а ссылка на новую папку скопируется в буфер. Окно Terminal можно закрыть нажатием Enter. При ошибке она выводится в Terminal; операция не считает себя успешной и ссылку не копирует.

Структура выбранных папок, включая скрытые файлы, и имена сохраняются внутри новой уникальной папки. Пустые папки Git не хранит; символьные ссылки и специальные файлы намеренно отклоняются, в том числе внутри папок. Файлы размером больше 50 МиБ не принимаются. Данные считываются в память и передаются GitHub API целиком по одному файлу; для больших наборов процесс может быть медленным. Бинарные и пустые файлы поддерживаются. Файлы, меняющиеся во время загрузки, не гарантированно образуют снимок.

Прогресс идёт по загруженным blobs; изменения становятся видны только после записи одного коммита в default branch. При изменении ветки другим участником инструмент делает до трёх попыток без force push. Если сеть оборвётся непосредственно после обновления ссылки на ветку, результат может быть неопределённым — проверьте репозиторий прежде чем повторять. Прерванная загрузка может оставить недоступные из веток Git blobs до их очистки GitHub.

## Удаление

Запустите `uninstall.command`. Оно удалит Quick Action, установленные файлы и сохранённый токен. Установленные отдельно uv и Python остаются. Чтобы также отозвать токен, удалите его в настройках GitHub.

## Разработка

`python3 -m unittest discover -s tests -v` запускает локальные тесты без доступа к GitHub. Установка, системные разрешения и Finder требуют проверки на реальном macOS 15. Исходный формат Automator собирается из системного action bundle; формат пакета и метаданные вдохновлены проектом [AutoAutomator](https://github.com/fullac/AutoAutomator).
